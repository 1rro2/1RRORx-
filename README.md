# 赵盟熙个人网站

数据驱动的全域营销 | 个人简历与作品集站点。

## 在线预览

- Vercel: https://1rrorx.vercel.app（示例）

## 技术栈

- HTML5 + TailwindCSS
- GSAP + ScrollTrigger（动画与滚动交互）
- 原生 JavaScript

## 本地运行

直接双击 index.html 即可预览，无需构建。

## 部署到 Vercel

1. 将本仓库推送到 GitHub
2. 访问 [vercel.com](https://vercel.com) 并导入该仓库
3. Framework Preset 选择 Other，直接部署

## 国内访问优化

本项目已将 TailwindCSS、GSAP、ScrollTrigger 等外部资源本地化到 ssets/js/，避免依赖境外 CDN。
